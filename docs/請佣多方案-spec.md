# 請佣與獎金多方案

## 操作

請佣獎金頁上方選擇方案。預設提供「一般請佣」及「配套請佣」，亦可新增具獨立額度的方案；建立時指定房屋或配套價格來源。每個方案各有 100% 請領額度、期別、佣金及獎金設定、紀錄、保留款與匯出版型。

方案可新增、編輯、刪除：

- 內建方案只能改名，價格來源固定，不可刪除。
- 自訂方案可改名；尚無請佣、獎金紀錄且未請領額度時，可變更價格來源或刪除。刪除以標記方式移出方案清單，設定與版型不連帶清除；後端驗證無歷史資料後才允許刪除。
- 名稱不可與其他方案重複。

價格來源：

- 一般合約沿用原成交房屋、車位及底價。
- 非一般合約的房屋方案可選「配套房屋總價（含車位）」或「原成交總價（含車位）」。採拆價時房屋底價預設為配套房屋總價減車位底價，可修改；有前次請佣則帶入前次底價。車位底價沿用銷控。
- 配套方案採成交總價減配套房屋總價；車位成交價、底價與車位資訊均不計入。配套底價必填。
- 同戶、同方案帶入最近有效請佣的價格來源及手填底價，供確認修改；每筆保存當次快照，後續修改不追溯歷史。
- 每筆請佣有「請佣備註」（非銷控備註），存於紀錄 `note`；戶別合約方式不是一般合約時，加入工作台即先帶入合約方式供編輯。請佣總表以「備註」欄顯示，既有版型自動補上此欄，可於版型隱藏；歷史匯入可用「備註」欄帶入。
- 匯出中心的請佣總表、獎金表及個人明細皆限目前方案。無紀錄時仍能設定版型。房屋／配套全域範本分開管理，套用範本為複製，不連動改寫。

以 C-15 的成交總價 3849 萬、配套房屋總價 3750 萬為例：房屋方案請佣總價 3750 萬，房屋成交價為 3750 減車位成交價；配套方案請佣總價 99 萬。手填房屋底價不含車位。

## 歷史匯入

- 房屋新範本新增「合約方式、價格來源、請佣總價(含車)、房屋底價」。價格來源可填「原成交總價」或「配套房屋總價」，空白時依戶別合約判定。C-15 拆價請佣總價填 3750，房屋底價不含車位。
- 配套新範本使用「配套價格、配套底價」，移除車位欄位；C-15 配套價格填 99。
- 檔案歷史數字優先於銷控現值；拆價房屋底價與配套底價須填歷史值。預覽列顯示合約方式、價格來源、請佣價格與總底價供核對。
- 舊房屋格式未帶價格來源時維持原成交價邏輯；舊配套格式仍接受房屋成交價／成交總價及房屋總底價／總底價作為別名，車位金額須為 0。
- 請佣、獎金都匯入目前方案，匯入範本檔名包含方案名稱。

## 資料與相容性

- 未帶 `planId` 的歷史資料皆視為 `general`，不批次改寫舊紀錄。
- 方案定義：`commissionPlans/{projectId}__plan__{planId}`，內建方案無須另建定義文件；內建方案改名時以同 ID 文件覆寫名稱，後端仍固定其價格來源。
- 設定：一般方案仍使用 `commissionSettings/{projectId}`；其他方案使用 `{projectId}__plan__{planId}`。
- Ledger：一般沿用 `{projectId}_{unitId}`；其他方案使用 `{projectId}__plan__{planId}_{unitId}`。
- 請佣、獎金、退佣、匯入、版型、保留款及稽核紀錄帶 `planId`。退佣來源不可跨方案；整期作廢、清除、覆蓋及撤銷匯入只處理該方案。
- 前後端需一併發布；一般及配套均使用更新後的 `submitCommissionEntries`。相關作廢、匯入及清除函式亦須更新，並新增發布 `manageCommissionPlan` 供方案 CRUD 使用。

### 匯出中心：方案合併／分檔（2026-09）

- 請佣總表與獎金表分別選擇「目前方案」「所選方案分開檔案（ZIP）」「所選方案合併同一 Sheet」。選擇以使用者及建案為鍵保存在目前瀏覽器；未設定時維持目前方案匯出。
- 所選方案依相同期別取有效紀錄；沒有資料的方案不建立空白檔案。方案指一般、配套及自訂請佣方案，不是依戶別合約名稱重新分類。
- 分檔下載為 ZIP，每個方案各一份 Excel／PDF。合併 Excel 為一張工作表，依方案及原請佣比例版面分區，保留各筆資料及各區小計，不將同戶不同方案壓成一筆。PDF 使用相同預覽內容。
- 各方案使用自己的設定；目前方案使用所選版型，其他方案使用各自預設版型。原獎金版型勾選附請佣總表時，附表也包含在合併內容中。沒有跨方案重新計算稅金或扣款。
- 每戶每人獎金以 commissionRecordId 關聯，避免同戶的多筆請佣、配套及退佣互相重複計入。
- 個人明細與 Email 維持目前方案範圍。

對應「請佣分檔、獎金同 Sheet」：請佣選「所選方案分開檔案（ZIP）」、獎金選「所選方案合併同一 Sheet」，勾選一般及配套方案。

### 建案方案名稱

在「請佣方案」選擇一般、配套或自訂方案後，使用「修改名稱」儲存本建案的顯示名稱（1～30 字，同建案不可重名）。已有請佣或獎金也可反覆修改，不需清除歷史資料；其他建案不受影響。

名稱沿用 commissionPlans 的建案專屬文件儲存，所有關聯仍使用固定 planId。改名不重建方案、不變更價格來源、設定、額度、保留款或歷史紀錄的名稱快照。畫面及新產生的匯出報表使用目前名稱；一般方案改名後，匯出標題／檔名也呈現新名称。修改名稱不重掛工作台，保留未送出的編輯內容。自訂方案的價格來源及刪除入口保留於「管理方案」。

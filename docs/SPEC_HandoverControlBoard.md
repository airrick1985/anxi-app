# 交屋控管表（驗屋預約 › 戶別資料管理）

範本：`交屋控管表-範本.xlsx`（富宇天雋）。樓層 × 棟線矩陣、店面另列一排、右側統計。

## 1. 入口與切換

- 戶別資料管理頁標題列加 macOS 分段切換：「戶別資料總表｜交屋控管表」。
- 左側抽屜「預約管理」也有「交屋控管表」入口（同一頁的 `?sheet=handover`），兩個選單項目依 `?sheet` 各自顯示選中。
- 切換狀態寫在網址 `?sheet=handover`，重新整理仍停在同一張表；從選單切換時頁面不重建，跟著網址切換分頁。
- 總表用 `v-show` 保留，切回來時篩選、捲動位置不變；控管表第一次切換才建立。
- 標題列按鈕依目前分頁切換：總表＝新增欄位／下載／上傳；控管表＝下載 Excel／設定。

## 2. 資料來源（全部沿用總表已在監聽的資料，不另開查詢）

- `households`（同建案）＋ `appointments`（狀態「預約中」「已完成」）。
- 已售：有買方姓名，或有任何有效預約，或交屋開關已開。其餘為未售。
- 預約完成：狀態「已完成」，或「預約中」但日期已過（排程漏跑時的保險）。
- 已約：狀態「預約中」且日期為今天以後（或未填日期）。

## 3. 每戶狀態（最近進度）

進度項目＝建案預約項目中被列入的項目，依設定順序由前到後。

1. 未售 → `unsold`
2. 交屋開關開啟 → 交屋項目的「已交屋」
3. 由最後一個進度項目往前找，第一個有資料的項目：
   - 有已約 → `booked:<項目>`（同一項目已完成又再約，以「已約」為準，提醒下一步）
   - 只有完成 → `done:<項目>`
4. 都沒有 → `pending`（未驗；若進度項目沒有任何「驗」字則顯示「未開始」）

預設進度項目：名稱含「驗」或「交屋」的預約項目，依 初驗 → 其他驗 → 複驗 → 交屋 排序；一個都沒有時列入全部預約項目。
建案沒有「交屋」預約項目時，自動補一個只有「已交屋」狀態的虛擬項目，對應交屋開關。

## 4. 矩陣排版

- 戶號解析：`A1-03`（棟線-樓層）、`2F-A3`（樓層F-棟線）、`A1-2F`。欄位用「棟別」欄，沒有才用戶號拆出的棟線。
- 棟別 `S`、`S1`… 或戶號 `S-01` 視為店面；無法解析樓層的戶別也放在下方「其他」排。
- 欄依棟線自然排序（A1, A2, …, B10），棟（A／B）之間留空隙並加棟名表頭（只有一棟時不顯示）。
- 列為樓層由高到低，左右兩側都標樓層；表頭與左側樓層固定（sticky），矩陣區塊內可橫向捲動。
- 不存在的格子留白。

格子內容：狀態文字；已約狀態第二行顯示預約日期（M/D）。滑過顯示戶號、買方、各項目預約日期。點格子開啟該戶「戶別整合資訊」。

## 5. 圖例、篩選、統計

- 圖例列每個狀態一顆：色點＋名稱＋戶數。點名稱可多選篩選（其他格子淡化），點色點直接改顏色（就地操作，選完即存）。
- 搜尋框（戶號／買方），不符合的格子淡化。
- 統計（寬螢幕在右側，窄螢幕在下方）：
  - 總戶數、已售／未售（占總戶數 %）
  - 已售未驗、已驗戶（任一含「驗」項目已完成）、交屋戶數（占已售 %）
  - 各進度項目：已完成戶數（進度條，占已售 %）與已約戶數
  - 附加統計：已撥款（撥款日有值）及設定勾選的自訂欄位（有值即計）

## 6. 建案層級設定 `projects/{projectId}.handoverBoard`

```
{
  stages: ['初驗', '複驗', '交屋'] | null,  // null = 用預設
  colors: { unsold: '#E5E5EA', 'booked:初驗': '#…', … },  // 沒設的用預設色
  extraStats: ['appropriationDate', '<自訂欄位名稱>'],
  updatedAt, updatedBy
}
```

- 設定視窗（macOS sheet）：狀態顏色（預設色盤＋自訂色）、進度項目（勾選、上下移排序）、附加統計勾選、全部還原預設。
- 預設配色採 macOS 系統色淡色系：未售灰、未驗淡琥珀，各項目「已約」淺色、「已完成」較深，交屋綠色。文字顏色依底色亮度自動黑／白。
- 前端直接 `updateDoc` 寫入 projects（與其他建案設定相同做法），不新增後端 API。

## 7. 下載 Excel

依範本版型：標題「建案-交屋控管表」、更新日期、樓層 × 棟線矩陣（套用建案自訂顏色）、店面排、右側統計與圖例。

## 7.1 複製圖片

- 工具列「複製圖片」：整張控管表（標題、更新時間、圖例戶數、完整矩陣不受捲動裁切、店面、統計）轉成 2 倍 PNG 寫入剪貼簿，可貼到 LINE、Email、Word、簡報。
- 有篩選／搜尋時圖片與畫面一致（不符合淡化），標題旁標出條件。
- 轉圖沿用 `utils/htmlToPng`（瀏覽器原生排版）。點擊當下就把產生中的圖片交給剪貼簿（Safari 規定）。
- 瀏覽器不能寫剪貼簿（LINE 內建瀏覽器、舊版瀏覽器）時改開預覽：長按／右鍵複製、下載 PNG、手機可分享。

## 8. 戶別整合資訊改 macOS 風格

- 視窗：淡灰標題列（可拖移）、戶號大字＋買方＋建案、右側「進入編輯／儲存並退出」「新增預約」、關閉鈕。
- 電腦版（≥900px）左側系統設定風格側欄：彩色圓角小圖示＋名稱＋摘要，選中藍底白字；視窗固定高度，切換項目不跳動。
- 內容改 macOS 分組表單（白色圓角群組、左標籤右內容），開關改 macOS 綠色 toggle，輸入框改 macOS 樣式；客戶回傳訊息改展開列。
- 手機（<600px）全螢幕顯示、不可拖移。
- 從整合資訊開啟的取消預約、發送提醒、新增／檢視回傳訊息、報告作廢／標記下載確認框一併改 macOS sheet。
- 功能、欄位、儲存流程完全不變。
